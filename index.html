上手要点
1. 左侧元件点一下或拖到画布，新元件会自动找空位，不会叠在一起；
2. 鼠标移到引脚（小圆圈）上按住，拖到另一个引脚就成一条线；把输入引脚拖到已有的线上会插入分线器形成分支，一个输出也能直接接多个输入（扇出）；
3. 蓝色空心引脚 = 悬空，值是 X（未知）。门的每个输入都连上才会输出 0/1，只连一半时输出必然是 X，这不是坏了；
4. 开关在画布上点一下就翻转；时钟靠「运行／单步」走拍，底部波形面板记录每一拍；
5. 右键元件或连线直接删除（Ctrl+Z 撤销）；触发器的采样沿在属性面板里切换上升/下降沿；
6. 波形太挤时，点波形面板左列的信号名就把这个元件的波形关掉，点底部「已隐藏 …↩」的名字恢复。

元件库

  • 输入：开关（点画布上的开关即可翻转）、时钟（可自动按节拍走，也可手动）。
  • 门：与/或/非/与非/或非/异或/同或/缓冲/二选一。多数门支持 2–4 个输入，在属性面板里改。
  • 时序：D 触发器、JK 触发器，默认在时钟上升沿（0→1）采样，属性面板可改成下降沿（1→0）；画布上 CLK 引脚标着 ↑ 或 ↓，一眼能看出这台触发器看哪个沿。把 Q̄ 接回 D 就构成二分频。
  • 沿是相对「上一拍」判断的：只有当时钟引脚的电平从 0 变 1（或 1 变 0）那一拍才写入 D/J/K，其它拍保持原值，所以手动时钟要先让它翻转一次。
  • 布线：分线器，1 入 n 出（2–6），把一条信号原样分成多份；属性面板里可调分支数。

仿真规则

  • 三值逻辑：1 高电平、0 低电平、X 悬空或未定（蓝色虚线）。门的输入没连满时输出就是 X，指示灯也不会亮——这是有意的，不把未知当成 0。
  • 与/或门有空传：只要有一个输入是 0，与门输出就是 0，即使别的输入悬空。
  • 组合反馈（如两个与非门交叉耦合）按不动点迭代求稳态；若 64 轮仍不收敛，HUD 会标红提示振荡，此时输出处于逐轮翻转的伪振荡状态，可用它近似看环振。
  • 触发器的复位/未连接输入按 0 处理，不建模亚稳态。

快捷键

  • Space 运行/暂停 · N 单步 · Del 删除选中 · 右键 删除命中的元件/连线 · Ctrl+Z 撤销 · Esc 取消当前连线/选择
  • 滚轮 以光标为中心缩放 · 中键或Alt拖拽平移 · Ctrl+滚轮同样缩放

连线与编辑

  • 从输出引脚拖到输入引脚；一个输入只跟一根线，重复连接会自动替换旧线（替换中的引脚显示黄色）。
  • 反向也支持：从输入引脚拖到输出引脚。点连线选中它，按 Del 删除。
  • 删除：右键点元件/连线即刻删除（元件若在一组多选里则整组删除），连带删掉挂在它上面的线；Ctrl+Z 可撤销。右键空白处什么都不做，不会误删。
  • 分支：从输入引脚起拖，松手时落在另一条线上，会在线的中点插入分线器，两个输入共享同一路信号；若那条线本身就来自分线器，则直接多加一条支路。
  • 扇出：同一个输出引脚可以拖出任意多条线，不必用分线器。
  • 新放置的元件会自动避开已有元件（从中心向外找空位），不会叠在一起。
  • 在空白处拖框可多选；多选后拖动任意一个，整组一起移动。
  • 输出可扇出到多个输入，输出接输出、输入接输入都不允许。

其它

  • 电路自动存在浏览器本地（localStorage），刷新不丢；「导出」可存成 JSON 文件分享。
  • 波形面板自动列出所有元件的输出（以及指示灯的输入），最多 24 条、保留最近 160 拍。
  • 关掉某个元件的波形：点波形面板左列的信号名即可隐藏它这一行（同一元件的 Q/Q̄ 一起关），再点波形底部「已隐藏 …↩」的名字就恢复；属性面板里也有「在波形面板显示」勾选框，走哪条路都一样。隐藏只是不画，数据仍在记录，恢复后历史不断档，且会随电路一起存档。

# 数电模拟器（Digital Lab）

单文件数字电路仿真网页：拖元件、连线、上电看波形。**只有一个 `index.html`，不需要安装、不需要联网、不需要构建工具**，浏览器直接打开就能用。

只仿真**数字**逻辑（三值 0 / 1 / X），不做 RC、运放这类模拟仿真。

---

## 打开方式

- 直接双击 `index.html`（`file://` 方式可用，包括本地存档功能）。
- 或者在本目录起个静态服务：`python -m http.server 8765` 后访问 `http://127.0.0.1:8765/index.html`。

推荐用 Chrome / Edge 最新版（需要 PointerEvent、Canvas 2D、localStorage）。

## 界面

```
┌ 顶栏：运行/暂停 · 单步 · 复位 · 节拍 Hz · 撤销 · 示例电路 · 真值表 · 保存/载入/导出/导入/清空 ┐
├ 左：元件库   中：画布（拖拽连线，滚轮缩放，中键或 Alt 拖平移）   右：真值表面板 ┤
└ 下：波形 / 属性 / 帮助 三个可切换面板（右上角「收起/展开」放大画布）┘
```

画布右上角的 HUD 实时显示节拍数、元件与连线数量、求解状态（稳定 / ⚠ 未收敛）。

真值表放在屏幕**右侧**的独立面板里，不想要时可以收掉（点面板右上的「收起」或顶栏「真值表」），收起后画布立刻占满整个宽度；详见下面的「真值表」一节。

## 三分钟上手

1. 左侧点一下元件（或拖到画布）→ 放置，**新元件会自动找空位**，不会叠在一起。
2. 鼠标移到引脚（元件边框上的小圆圈）按住，拖到另一个引脚松手 → 成一条线。
   - 从**输入**引脚起拖、松手时落在**另一根线上** → 在线的中点插入分线器，信号分出支路。
   - 一个输出引脚可以拖出多条线（扇出），不必用分线器；输出接输出、输入接输入会被拒绝。
3. 点顶栏「运行」或按 `空格` 开始走拍，底部波形面板按拍记录每个信号的电平。
4. 屏幕右侧就是「真值表」面板：选中一个元件看它自己的真值表/功能表；切到「整个电路」就按眼下的开关组合穷举所有输入，绿底那行就是现在的状态。

## 元件库（24 种）

| 分类 | 元件 | 说明 |
| --- | --- | --- |
| 输入 | 开关 SW | 在画布上点一下就翻转 |
| 输入 | 时钟 CLK | 可「自动按节拍翻转 + 分频 1~32」，也可改成手动（点击翻转） |
| 输出 | 指示灯 LED | 输入为 1 时点亮 |
| 输出 | **数码管 SEV** | 七段数码管，`a~g` 七个段码脚，**高电平点亮**；接 74LS48 的同名输出脚就能显示数字，悬空的段不亮 |
| 输出 | **数显 NUM** | 8421 数显，`A(1)/B(2)/C(4)/D(8)` 四位码直接显示，**自带译码**不用加芯片；显示 0~9 与 `A、b、C、d、E、F`（七段画不出大写 B/D，按真数码管习惯用小写），有悬空脚显示 `?` |
| 门电路 | AND OR NOT NAND NOR XOR XNOR BUF | 与/或/非/与非/或非/异或/同或/缓冲；除 NOT、BUF 外支持 2~4 个输入，属性面板可改 |
| 门电路 | MUX 二选一 | `S=0` 选 D0，`S=1` 选 D1 |
| 门电路 | 分线器 SPLIT | 1 入 n 出（2~6），把同一路信号复制多份 |
| 时序 | D 触发器、JK 触发器 | **可选上升沿或下降沿采样**，画布上 CLK 引脚标 `CLK↑` / `CLK↓`；Q̄ 接回 D 即二分频 |
| 74 芯片 | **74LS86** 四异或 | 8 入 4 出，`1Y=1A⊕1B`、`2Y=2A⊕2B`……一片顶四个异或门 |
| 74 芯片 | **74LS125** 四三态缓冲 | 每路一个数据脚 `A` + 一个**低有效**使能脚 `Ḡ`：`Ḡ=0` 时 `Y=A`，`Ḡ=1` 时输出**高阻**（画成蓝色 X，等于没接） |
| 74 芯片 | **74LS74** 双 D 触发器 | `1CP`/`2CP` 两个时钟脚，固定**上升沿**，两路互不影响；另有 `R̄D`/`S̄D` 异步端——`R̄D=0` 立即清 0、`S̄D=0` 立即置 1，**不等时钟沿**；两者同时为 0 时 Q 与 Q̄ 都是 1（真芯片如此） |
| 74 芯片 | **74LS90** 二-五-十进制计数 | `CPA` 驱动二分频（QA），`CPB` 驱动五分频（QD/QC/QB），两个脚都是**下降沿**有效。**QA 接 CPB、时钟进 CPA** 即 8421 十进制 0~9；只接 CPA 是 ÷2，只接 CPB 是 ÷5。`R0(1)=R0(2)=1` 清 0，`R9(1)=R9(2)=1` 置 9，优先于计数。输出脚顺序 **QA、QD、QC、QB**，权重 1、2、4、8 |
| 74 芯片 | **74LS48** BCD 译码七段 | `A(1)B(2)C(4)D(8)` 进、`a~g` 出，高电平有效，输出脚与数码管一一对应。输入 10~15 时七段全消隐；任一输入悬空则输出全 X。**不建模** `LT/RBI/BI` 测试与消隐端 |
| 74 芯片 | **74LS175** 四位并行寄存器 | `D0~D3` 四路数据，`CP`（固定**上升沿**）一来同时打进 `Q0~Q3`，没沿就保持；`MR̄=0` **不等时钟**立刻四路全清 0 |
| 74 芯片 | **74LS194** 四位双向移位 | `CP` 上升沿按 `S1S0` 动作：`00` 保持、`01` 右移（`DSR→Q0→Q1→Q2→Q3`）、`10` 左移（`DSL→Q3→Q2→Q1→Q0`）、`11` 并行置入 `I0~I3`；`CR̄=0` 立刻清 0 |
| 布线 | （见上 SPLIT） | 线中间插入即可分支 |

74 芯片按**整片**建模：一个元件就是一块芯片，引脚名与真芯片一致，属性面板会把固定沿和异步端写在徽章/提示里。

## 仿真规则

- **三值逻辑**：`1` 高电平、`0` 低电平、`X` 悬空/未知（蓝色）。**门的输入没连满时输出就是 X，指示灯也不亮，这不是坏了**——不把未知当成 0。
- **与/或吸收律**：与门只要有一个输入是 0 就输出 0；或门只要有一个输入是 1 就输出 1，其余输入悬空也一样。
- **组合反馈**（例如两个与非门交叉耦合的 SR 锁存）用不动点迭代求稳态；64 轮仍不收敛会在 HUD 标红提示「未收敛（组合环振荡）」，可用来近似观察环振。
- **时序元件**不参与上面的迭代，只在时钟**沿**到来的那一拍采样 J/K/D；触发器悬空输入按 0 处理，不建模亚稳态。
- 电平是**按引脚**记录的，所以一片芯片可以有多个时钟脚、各自的沿（LS74 两个上升沿、LS90 两个下降沿），异步端（`R̄D/S̄D`、`R0/R9`）则在每一拍先于沿生效。
- 一片内或级联间的**纹波进位**不会漏数：如果某次采样让别的输出翻转、而那个输出又是另一片（或自己）的时钟脚，内核会在同一拍内再采样一轮直到不再变化，最多 6 轮。所以 LS90 把 QA 接回 CPB 能正常数到 0~9。
- **显示元件是纯接收**：指示灯、数码管、数显都没有输出脚，只负责画，不参与求解；波形面板里列的是它们的输入（数码管/数显列成 `.IN(脚名)`）。
- 横轴是**拍号**而不是真实时间：1Hz 和 10Hz 下波形形状完全一样，只是走得快慢不同。

## 交互细节

- **删除**：`右键` 点元件/连线直接删（元件会连带删掉挂在它上面的线；若该元件在一组多选里则整组删除），右键空白处什么都不做；`Del` 删除选中项。删完可用 `Ctrl+Z` 撤销。
- **属性面板**：选中元件后可改名称、输入数、分支数、时钟模式/分频、D/JK 触发器的**上升沿/下降沿**、以及是否在波形面板显示。74 芯片的沿是芯片规格定死的（LS74/LS175/LS194 上升沿、LS90 下降沿），面板里显示成固定文字并列出各时钟脚名，没有下拉框。带规格约束的元件（74 芯片、数码管、数显）面板底部还会多出一行**说明**，写清楚有效电平、异步端和消隐规则。
- **波形面板**：自动列出所有元件的输出（指示灯列出它的输入），最多 24 条、保留最近 160 拍、画面显示最近 80 拍。**点左列的信号名就把这个元件的波形收起来**（同一元件的 Q/Q̄ 一起收），点底部「已隐藏 xxx ↩」的名字或属性面板里的勾选框恢复；隐藏只是不画，数据仍在记录，恢复后历史不断档。
- **多选与移动**：空白处拖框多选，`Shift` 点选追加；多选后拖动任意一个整组移动。
- **视图**：滚轮以光标为中心缩放，`+` `−` `适应` 按钮，中键或 `Alt` 拖拽平移。

## 真值表

真值表在屏幕**右侧**的独立面板里：顶栏「真值表」按钮或面板右上「收起」随时开关，收起后画布占满整个宽度（窗口窄于 900px 时面板折到画布下方）。面板顶上两个按钮切模式。表**每次仿真后现算**：改连线、拨开关、走一拍都会自动刷新，不需要手动点「生成」；列比较宽时在面板里横向滚动。

**选中元件**（正好选中一个元件时才有意义）：

| 元件 | 给出的表 |
| --- | --- |
| 门电路、MUX、分线器、74LS86/125 | 按输入穷举自动生成的真值表；最左一列是最高位，最多穷举 6 个输入（多出来的脚按当前电平固定）。74LS86/125 四路完全一样，表只按第一路列，面板上会写明其余路的脚名 |
| 74LS48 | 译码表 `D(8) C(4) B(2) A(1)` → `a~g` + 显示字形（输入 10~15 那几行写「消隐」） |
| D/JK 触发器、74LS74/90/175/194 | **功能表**：哪个沿做什么、异步端（`MR̄`/`CR̄`/`R0`/`R9`）优先于沿；`–` 表示该脚无关，`↑` 表示时钟沿。这些元件的输出还取决于历史状态，穷举输入没有意义 |
| 数码管 SEV | **段码表**：`0~9` 与 `A b C d E F`、`-` 的标准字形，每段写 `1`（亮）/ `0`（不亮）；自己拼的字形不在表里，画布照样显示 |
| 8421 数显 NUM | **译码表**：四位码 → 显示字形（同样按数据手册把高位写在左边） |
| 开关 SW、时钟 CLK | 不出表，面板里给一句说明：开关只有 0/1 两个电平，自动时钟的输出只跟着节拍走。要把它们当输入列举，用「整个电路」模式 |

**整个电路**：把电路里的**开关**和**手动模式的时钟**（属性面板取消勾选「跟随节拍自动翻转」）当输入，n 个输入列 2ⁿ 行，最多枚举 6 个输入；输出列依次是各元件的输出脚，最多 14 列，其中指示灯列写「亮/灭」，数码管与数显列直接写它显示的字形。

两种模式都会把**当前输入组合**所在那一行标成绿底、行末写「当前」；输入脚有悬空（X）时不高亮，因为那一行本来就不在 0/1 穷举里。生成整电路表时会临时改动开关电平、算完立刻还原，不会留下副作用；时序元件在表里保持当下已经锁住的状态，不会在表里逐个时钟沿展开。

## 存档

- **自动保存**：改动约 0.7 秒后写进浏览器 localStorage，刷新不丢。按域名/路径隔离，所以 `file://` 打开和 `http://127.0.0.1` 打开是两份不同的存档。
- **保存 / 载入**：手动写/读那份本地存档。
- **导出 / 导入**：存成 JSON 文件，便于换电脑、发给别人或留多个版本。文件格式就是内部结构：

  ```json
  { "v": 1, "tick": 0, "nextId": 74,
    "comps": [{ "id": 59, "type": "XOR", "x": -608, "y": 181, "props": { "n": 2 } }],
    "wires": [{ "a": { "id": 59, "p": 0, "side": "out" }, "b": { "id": 60, "p": 1, "side": "in" } }] }
  ```

  元件 `props` 里可能出现的字段：`label` 名称、`n` 输入数、`m` 分线器分支数、`state` 开关/手动时钟电平、`auto` + `div` 时钟模式与分频、`edge` 触发沿（`1` 上升沿 / `0` 下降沿，缺省按上升沿；只对 D/JK 触发器有意义，74 芯片的沿固定写在代码里）、`scope` 是否在波形显示（`false` 为隐藏，缺省显示）。
- 旧存档字段缺失时按默认值补齐，不会因为版本演进而打不开。

## 自带示例电路

顶栏「示例电路」下拉可一键载入（会先快照，可撤销）：

1. **D 触发器二分频** —— 时钟进 CLK，Q̄ 接回 D，每两个拍 Q 翻转一次。
2. **NAND 交叉耦合 SR 锁存** —— 组合反馈求稳态，两个开关看置位/复位。
3. **一位全加器** —— 两级异或 + 两个与门 + 一个或门，Sum 与 Cout。
4. **74LS90 十进制计数** —— 时钟进 CPA、QA 接 CPB，四个指示灯显示 8421 码 0~9，开关同时接 `R0(1)/R0(2)` 做清零。
5. **74LS48 + 数码管显示** —— 同样一片 LS90 计数，一路直接进 8421 数显，另一路过 74LS48 驱动外接七段数码管，数到 0~9 两种显示同步。
6. **74LS175 四位寄存器** —— 四个开关喂 `D0~D3`，时钟设成 ÷2；改完开关要等下一个上升沿才进 Q，`MR̄` 开关按下立刻清零。
7. **74LS194 移位寄存器** —— 预置 `S1S0=11` 先并行载入 `1000`，把 `S1` 拨回 0（=01）就看着那个 1 往高位跑，`S0=0/S1=1` 变左移，`CR̄` 清零。

本目录里的 `二位全加器.json` 就是用「导出」存下来的自建电路，用「导入」即可放回画布。

## 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 门有输出但指示灯不亮、值显示 X | 输入没连满，或上一级本身就是 X。把每个输入都连上；蓝色虚线引脚就是悬空输入 |
| 触发器不跟着时钟动 | 检查时钟是不是接到了 J/K/D 而不是 CLK（引脚名直接标在画布上）；手动时钟要先让它翻转一次才产生沿；上升/下降沿设置和时钟当前相位不匹配。74LS90 是**下降沿**计数，LS74 是**上升沿**，画布引脚上的 `↑/↓` 就是它看哪个沿 |
| LS90 数不到 9 或一直 0 | 十进制要把 **QA 接到 CPB**、时钟只进 CPA；`R0(1)` 或 `R9(1)` 悬空即可（悬空＝未有效），接了高电平会被一直清零/置九 |
| 按「运行」但拍数不动 | 页面切到后台时浏览器会节流 `requestAnimationFrame`，切回前台即恢复；用「单步」可确认逻辑本身没问题 |
| HUD 显示 ⚠ 未收敛 | 存在组合环（例如门输出直接短接回自己输入）。加一级触发器或断开反馈 |
| 连线连不上 | 只能从输出引脚连到输入引脚；一个输入只跟一根线，重复连接会替换旧线 |
| 波形行太多看不清 | 点信号名把不关心的元件收起来，或点「展开」把下方面板拉高 |
| 数码管一段都不亮 | 段码是高电平有效，输入为 `0` 或 `X` 都不亮。接 74LS48 时先确认译码器的 `A~D` 都连上了（悬空输入 → 输出全 X → 七段全不亮）；只想看数就不用管数码管，直接放 **8421 数显** |
| 数显显示 `?` | 四位 8421 码里有脚悬空。数显不把未知当 0，所以宁可显示 `?`；把 `A/B/C/D` 都连上就出数字 |
| 寄存器 Q 一直是 0 | 74LS175/LS194 只在 CP **上升沿**动作：数据要先备好，再等时钟从 0 变 1 那一拍；`MR̄/CR̄` 若被拨到 0 会一直压住清零。LS194 还要看 `S1S0`，`00` 是保持、`11` 才是并行置入 |
| 真值表没有绿底「当前」行 | 这一组输入不在 0/1 穷举里：某个输入脚悬空（X），或输入多于 6 个只枚举了前 6 个。把线连满就会高亮 |
| 真值表提示「还没有可枚举的输入」 | 电路里只有自动时钟（跟着节拍走的不算输入）。放几个开关，或把时钟属性改成手动 |

## 已知限制

- 只做数字逻辑：没有延迟模型、没有建立/保持时间、不模拟亚稳态与毛刺宽度。
- 三态只做到「高阻 = X」这一层（74LS125 禁用时输出显示为 X，等价于这根线没接）；没有真正的共享总线模型，两个输出直接对接不会做线或与冲突检测。
- 芯片按功能建模，不含负载效应、驱动能力和引脚编号（如 LS90 只给功能名 QA/CPA，不给 14 脚封装的脚位号）。
- 显示与寄存只做常用部分：74LS48 不建模 `LT/RBI/BI`，也没有消隐级联，输入 10~15 一律全灭；数码管把 `X` 当「不亮」画（数显才会标 `?`）；74LS175/LS194 只给 Q 输出，不做 Q̄，LS194 也没做 `Q0'/Q3'` 串行级联脚——要多片级联就在 S/PPT 之外自己接。
- 波形最多 24 条、窗口 80 拍，不能横向缩放或滚动导出。
